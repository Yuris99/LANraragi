# 태그 표시와 원본 바로가기

태그 언어 선택에서 한국어 / English를 바꾼다. 이 선택은 `studio-view`에 브라우저별로 저장한다. 목록·태그 선택·작품 상세·출처 태그의 표시를 함께 바꾸며, 열린 상세 화면·리더·선택한 필터는 유지한다. 입력·이름 변경·내보내기에는 원문 태그를 사용한다.

한국어·영어 태그 이름을 모두 검색할 수 있다. `female:glasses`, `여성:안경`처럼 분류를 지정하면 해당 분류만 찾는다. 검색과 분류를 적용한 다음 상위 100개를 반환하므로 다른 분류의 인기 태그 때문에 해당 분류가 누락되지 않는다. 필터 URL·DB 값·출처 기록의 태그는 원문을 유지한다.

태그에 마우스를 올리면 브라우저 기본 툴팁으로 한국어 대응어·원문·설명·분류를 표시한다. 태그 옆 정보 버튼을 클릭·터치하거나 키보드로 선택해도 같은 내용을 열 수 있다. 버튼 설명은 모달을 추가하지 않는 팝오버로 표시하며 Esc·닫기·바깥 클릭으로 닫는다. 번역·설명이 없는 항목은 미등록임을 표시한다. 작가명과 캐릭터·원작 이름의 분류를 섞어서 번역하지 않는다. 사용자 태그 편집란에는 원문을 그대로 표시한다.

번역 대응표는 [project-violet/tag-info](https://github.com/project-violet/tag-info/tree/51233c8df9fd5d2247a82865ebef29cad8664b26)의 공개 도메인(Unlicense) 자료를 고정해 포함한다. 원본의 `LICENSE` 전문은 `tag_dictionary_data.py`에 포함한다. 해당 리비전의 `result-korean-tag.json`, `result-korean-series.json`, `result-korean-character.json`, `result-korean-merge.json`, `LICENSE`를 로컬 폴더에 저장한 다음 아래 명령으로 재생성할 수 있다. 빌더는 원본 Git blob SHA를 검증한다.

```sh
python -B studio/tools/build_tag_dictionary.py /path/to/upstream
```

추가 표시명·간단한 설명은 `tag_display.py`에 있다. 설명이 없는 항목을 추측해서 채우지 않는다. 실행 중 외부 번역 서비스나 사전 서버를 호출하지 않으며, 사전 API도 Studio 인증 안에서 제공한다. DB·LANraragi 태그를 번역문으로 갱신하는 작업은 없다.

작품 카드와 상세의 사이트 아이콘은 사용자가 제공한 히토미 이미지와 이헨·익헨 공용 EH 이미지를 사용한다. 원본 PNG 바이트를 기존 SVG 심벌에 포함해 외부 파비콘을 요청하지 않는다. 등록된 출처만 표시하며, HTTPS·원래 사이트 호스트를 확인한 주소만 링크로 만든다. 이헨·익헨은 공용 아이콘 옆에 각각의 이름을 표시하고 실제 링크는 저장된 원본 주소를 유지한다.

이미지 검색은 기존 이헨·익헨 이미지 지문 검색을 사용한다. 히토미는 현재 작가·제목 후보 검색이며 히토미 자체의 역이미지 검색 기능은 구현하지 않았다.

nHentai는 사이트 목록·필터·로그인·신규 연결·다운로드·번호 후보 조회에서 제외했다. 이미 저장된 출처·태그·댓글·번호 기록은 읽기·복원 호환성을 위해 보존한다. 기존 기록에 대한 원격 갱신과 신규 작업 요청은 Studio API에서 거부한다. 로그인 서비스 이미지와 세션 파일은 이번 변경으로 다시 만들거나 삭제하지 않는다.

태그 조합 프리셋은 선택한 태그를 **모두 포함**하는 작품을 찾는다. 이름을 붙여 최대 40개, 조합당 태그 12개까지 저장·수정·삭제할 수 있다. 정의는 Studio의 기존 설정 테이블에 저장하므로 다른 기기에서도 공유된다. 태그 조건은 원문 키의 반복 `all_tag` 매개변수로 주소에 담아 새로고침·북마크·뒤로가기를 유지한다. 프리셋 삭제는 적용 중인 검색 조건이나 작품 태그를 지우지 않는다.

만화 주소는 `/manga`, `/manga/E123`, `/manga/E123/6`, `/manga/downloads`처럼 표시한다. 서버는 정해진 화면 경로만 인증 후 제공하며, `/api` 오류·알 수 없는 파일·`/audio/`를 만화 앱으로 돌리지 않는다. 과거 `/library`, `/E123`, `/#/…` 북마크와 UUID 주소는 `/manga` 아래의 새 주소로 바꿔 열고 검색 조건과 페이지 번호를 유지한다. `/audio/`는 별도 오디오 스튜디오의 일반 링크다. 과거 `/unsen`의 보기 상태는 해당 탐색 기록에 보관하고 일반 방문의 저장된 블러 설정은 유지한다.

한 번 읽은 만화는 상세 화면에서 `이어보기 · N쪽`과 `처음부터`를 함께 제공한다. 전자는 저장한 쪽, 후자는 1쪽을 열며 실제로 열린 쪽의 기존 진도 저장 방식을 따른다. 아직 읽지 않은 만화는 `읽기` 버튼 하나를 제공한다.
