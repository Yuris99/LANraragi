# 보이스코믹·번역 판본과 이미지 검색

Studio의 기존 등록 항목을 각각 독립적인 **판본**으로 유지합니다. 같은 작품의 원본·여러 번역본·보이스코믹은 상세 화면의 **판본 정보 · 같은 작품 연결**에서 다른 판본의 L번호 또는 이미 연결한 출처 번호를 지정해 묶습니다. 파일, 작품 UUID/L번호, 출처 URL·태그·댓글, 즐겨찾기, 만화 읽기 기록과 음성 재생 위치는 합치거나 덮어쓰지 않습니다. 같은 제목·번호·표지라는 이유로 자동으로 묶지 않습니다. 이미 다른 묶음에 속한 두 항목은 자동 통합하지 않으며 먼저 분리해야 합니다. 묶음 분리는 파일을 이동하거나 지우지 않습니다.

상세 화면에서 언어, 판본 이름, 번역자·번역팀과 형태를 지정합니다. 목록도 판본별로 표시하며 언어·판본 이름을 보여줍니다. 다른 판본은 상세 화면의 버튼으로 이동합니다. 출처 번호는 원래 연결한 판본으로 계속 열리고 각 판본의 L번호도 유지됩니다. 동일 출처 URL을 여러 판본에 복제하지는 않습니다. 그 URL과 수집 이력은 소유 판본에 보존하고 묶음에서 해당 판본으로 이동합니다.

## 영상형

**작품 추가 → 보이스코믹 · 영상**으로 CBZ나 외부 출처 없는 영상 전용 항목도 만들 수 있습니다. 상세 화면의 **영상·음성·표지 첨부**에서 MP4 또는 WebM을 첨부합니다. 위쪽 재생 버튼 또는 영상의 기본 컨트롤로 재생하며 시간 이동, 재생 속도와 파일 다운로드를 지원합니다. 재생 위치는 파일별로 약 5초 간격과 일시정지·탐색 때 저장합니다. 갑작스러운 종료에서는 마지막 저장 이후 구간이 남을 수 있습니다. 다른 판본·다른 트랙의 재생 위치를 공유하지 않습니다.

MP4의 H.264/AAC 조합은 생성한 영상으로 Chromium에서 실제 디코딩을 확인했습니다. WebM 및 다른 코덱은 브라우저 지원에 따르며 모든 조합을 검증한 것은 아닙니다. 서버에서 자동 변환하지 않아 NAS에 영상 변환 부하를 추가하지 않습니다. 파일 헤더/확장자 확인은 전체 코덱·컨테이너 무결성 검사가 아닙니다.

## 만화+음성형

**보이스코믹 · 만화+음성**을 선택하고 음성 파일을 첨부합니다. 이 판본에 연결된 CBZ를 그대로 사용하거나, **함께 재생할 만화 번호**에 별도의 CBZ 판본 번호를 입력합니다. 다른 만화 파일의 사본을 새로 만들지 않습니다. CBZ가 아직 준비되지 않았다면 먼저 해당 판본의 일반 읽기로 페이지를 준비합니다.

각 음성 아래 **페이지별 음성 시작 시간**을 `쪽=초` 형식으로 저장합니다. 예: `1=0`, `2=12.5`, `3=28`. 음성이 해당 시간에 도달하거나 탐색하면 연결한 페이지가 표시됩니다. 이전·다음 페이지 버튼은 등록한 시작 시간으로 이동합니다. 페이지와 시간은 중복 없이 증가해야 하며 범위를 벗어나면 기존 연결을 보존하고 거부합니다. 자동 음성 인식·페이지 추정, 강제 정렬이나 구간 반복 기능은 포함하지 않습니다.

WAV 재생·시간 이동·페이지 동기화·이어 듣기를 생성한 자료로 검증했습니다. MP3/M4A/FLAC/Ogg도 헤더와 MIME을 지원하지만 각 코덱은 실기기 검증 전입니다. 동인음성 전용 보관함은 이번 기능에 포함하지 않습니다.

## 파일과 백업

영상·음성과 JPG/PNG/WebP 표지는 기존 전용 Studio 업로드 볼륨의 `.voice-assets` 아래에 전체 SHA-256 기반 이름으로 저장합니다. 표지를 새로 첨부하면 해당 판본의 현재 표지를 바꿉니다. 파일을 덮어쓰지 않으며 동일 바이트/확장자를 재사용해도 판본별 트랙 ID·재생 기록은 독립적입니다. 임의 NAS 경로나 외부 URL로 파일을 가져오는 기능은 없습니다. 업로드한 미디어는 LANraragi 만화 색인에 전달하지 않습니다.

파일 제한은 기존 업로드 설정을 사용합니다(기본 512MiB, 설정 상한 2GiB). 표지는 최대 10MiB, 화면에서는 한 번에 20개를 순차 업로드합니다. 전송 중단 파일은 등록하지 않으며 저장 경로의 심볼릭 링크를 거부합니다. 서비스가 강제 종료되면 미등록 임시/게시 파일이 남을 수 있으며 원본을 지우는 자동 정리는 하지 않습니다. HTTP 인증과 동일 출처 쓰기 검사를 유지하고, 미디어는 인증된 단일 Range GET/HEAD로 제공합니다.

SQLite 백업에는 판본 묶음·참조, 첨부 메타데이터, 페이지 연결과 재생 위치, 이미지 지문이 포함됩니다. **실제 미디어 바이트는 SQLite에 없으므로 업로드 볼륨도 함께 백업해야 합니다.** 백업 보고에는 관련 테이블 수도 포함합니다. 파일 기반 백업은 쓰기를 중단하고 DB와 볼륨을 함께 보존해야 합니다. 기존 CBZ와 LANraragi 저장소는 종전 별도 백업 절차를 유지합니다.

이 스키마에 맞춘 현재 코드의 사본 통합은 판본/미디어가 있는 항목을 자동 통합하지 않고 보류합니다. 이전에 배포된 고정 버전의 유지보수 스크립트는 이전 런타임을 적용할 수 있으므로 새 판본/미디어를 등록한 뒤 과거 사본 정리 스크립트를 재실행하지 마세요. 앱 코드 롤백은 추가 테이블/미디어를 삭제하지 않지만 이전 UI에는 새 기능이 보이지 않습니다.

## 이미지 검색

**이미지로 작품 찾기 → 보관함 표지 색인·갱신**에서 기존 표지를 브라우저에서 순차 처리하고, 작은 64비트 밝기 변화 지문만 NAS의 SQLite에 저장합니다. 색인은 중지할 수 있고 실패한 표지는 건너뜁니다. 표지가 바뀌면 다시 갱신합니다. 이후 JPG/PNG/WebP 검색 이미지를 선택하거나 상세 화면의 **이 표지로 비슷한 작품 찾기**를 사용합니다. 검색 사진 자체는 서버에 업로드하지 않습니다. 가까운 지문 후보를 최대 40개 표시하며 기존 썸네일 블러 설정을 적용합니다.

이것은 비슷한 표지를 찾는 근사 검색입니다. 잘린 이미지·회전·다른 구도·내용의 의미까지 이해하는 검색은 아닙니다. 단색이나 단순한 표지는 다른 작품과 같은 지문을 가질 수 있습니다. 거리 0도 작품 동일성이나 판본 연결의 증거로 사용하지 않습니다. 외부 작품 식별 API나 대량 라이브러리 성능 벤치마크를 완료한 기능으로 표시하지 않습니다.

외부 원본 검색은 **외부 검색용 표지 저장** 후 Google Lens, TinEye 또는 SauceNAO를 열어 파일을 직접 선택하는 방식입니다. Studio가 원본 이미지를 외부 서비스로 자동 전송하거나 검색 결과를 수집하지 않습니다. 실제 제출 시에는 선택한 서비스에 이미지가 전달됩니다. 외부 사이트의 로그인·접근 제한을 우회하지 않으며, 결과 확인과 출처 연결은 사용자가 진행합니다. 링크와 무전송 동작은 검증했으나 외부 사이트 검색 성공을 검증한 것은 아닙니다.

## 검증 범위

합성 DB/HTTP 검증은 판본별 정체성·출처·읽기 기록 보존, 명시적 묶음·분리와 충돌 거부, 미디어 중복 저장 방지, 판본별 재생 위치, 잘못된 시간/페이지 및 타 판본 파일 거부, 중단 업로드·심볼릭 링크 거부, 인증·작업자 토큰·동일 출처 경계, Range 응답, SQLite 백업/복원과 지문 순위를 확인합니다.

생성한 H.264/AAC MP4·WAV·PNG를 실제 로컬 Studio/Chromium에서 재생하고 이어 듣기, 페이지 전환, 속도 변경, 업로드, 번역 판본 이동, 표지 검색과 PC/모바일 화면을 확인합니다. 별도 Docker/LANraragi 구성에서는 실제 합성 CBZ 페이지와 WAV를 연결해 재생·범위 다운로드·서비스 재시작 후 그룹/시간표/재생 위치 보존 및 원본 읽기 전용 보존을 확인합니다. Docker 테스트는 독립 클라우드 인스턴스이며 실제 NAS 설치/검증과 구분합니다. 개인 자료나 외부 검색 결과는 테스트에 사용하지 않습니다.
