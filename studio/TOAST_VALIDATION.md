# 모달 알림 표시 수정

일반 z-index로 모달보다 위에 표시할 수 없던 알림을 활성 모달 내부의 manual popover로 표시합니다. Popover 미지원 브라우저에서는 활성 모달 내부에 알림을 배치합니다.

실제 로컬 서비스와 Chromium에서 합성 자료만 사용해 기존 판본·미디어·이미지 검색 흐름 및 1440px/390px 화면의 중첩 모달, 스크롤 후 알림 위치와 실제 표시 순서, 닫힌 모달에서 이전 모달로 복귀, 입력 포커스 유지, 시간 만료 후 알림 제거를 검증했습니다. JS 구문 검사와 diff 검사도 통과했습니다. NAS 설치 성공 여부는 현지 업데이트 상태로 별도 확인해야 합니다.

다운로드 엔진이나 사이트 지원 범위를 변경하지 않습니다.
