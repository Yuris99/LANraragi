번호로 열기

보관함에 연결된 작품을 엽니다. 히토미는 숫자, E-Hentai는 E번호·익헨은 X번호, 출처 없는 작품은 L번호를 입력하세요.

태그 조합 프리셋

선택한 태그를 모두 포함하는 작품을 찾습니다. 프리셋은 스튜디오에 저장되어 다른 기기에서도 사용할 수 있습니다.

태그별 보기

사용자 태그와 작품·출처 태그에서 선택합니다. 숫자는 전체 보관함의 작품 수입니다.

파일 관리

연결된 NAS 자료는 다시 업로드할 필요가 없습니다. 아래 업로드는 PC 자료를 직접 추가할 때 사용하세요.

CBZ·ZIP·PDF를 올릴 수 있습니다. 파일 저장 후 보관함 색인을 기다립니다. 같은 파일은 중복 저장하지 않으며 기존 파일을 덮어쓰지 않습니다.

파일을 여기로 끌어 놓거나 아래에서 선택하세요.

태그 편집

사용자 태그만 변경합니다. LANraragi·출처 원본 태그는 보존됩니다.

사용자 태그 관리

모든 작품의 사용자 태그 이름을 바꿉니다. 이미 있는 태그면 하나로 통합합니다.

작품 추가

번호만으로 자동 연결하지 않습니다. 같은 작품인지 확인한 출처를 연결하세요.

번호·URL로 가져오기

다운로더 연결 필요 · 사이트별 실제 다운로드 검증 전입니다. 번호 확인만으로 파일이 저장되지는 않습니다.

E-Hentai는 처음 등록할 때 전체 URL이 필요합니다. 저장된 출처는 번호만 입력해도 됩니다.

실행 가능한 다운로더가 필요합니다. 사이트별 실제 다운로드는 아직 검증되지 않았습니다. 로그인·접근 제한을 우회하지 않으며, 번호가 같아도 출처가 다르면 별개로 처리합니다.

보기 설정

목록의 썸네일에만 블러를 적용합니다. 작품을 열면 상세 화면과 리더는 원본으로 표시합니다.

보기 설정은 이 브라우저에 저장합니다. 원본 파일과 서버 설정은 바뀌지 않습니다.

번호·작가 정리

파일명은 추정 근거입니다. 번호만 같다고 자동 연결하거나 합치지 않습니다. 연결 사이트 확인은 이 NAS에서 공개 메타데이터를 요청하며 개인 파일을 전송하지 않습니다. 로그인·차단을 우회하지 않습니다.

통일 파일명은 미리보기입니다. 이 화면은 NAS 파일을 이동·삭제하지 않습니다. 기존 사본 정리는 내용 검증과 작품 정보 보존을 거쳐 별도로 실행해야 합니다.

이미지로 작품 찾기

내부 검색은 비슷한 표지 후보를 찾습니다. 같은 작품인지 자동 확정하지 않습니다. 검색 사진은 브라우저에서만 처리하고 작은 지문만 NAS에 전송합니다.

외부에서 원본 찾기

아래 검색 사이트를 열어 이미지를 직접 선택하세요. Studio가 이미지를 자동 제출하지 않습니다. 선택한 사이트에 제출하면 그 사이트로 이미지가 전송됩니다.

사이트 연결 · 로그인

이 NAS 로그인 화면에서는 사이트의 사람 인증이 완료되지 않을 수 있습니다. Cloudflare는 자동화 브라우저를 실제 인증 지원 대상에서 제외합니다. 지원 브라우저 안내

일반 브라우저에서 직접 확인: E-Hentai·ExHentai 로그인. PC에서 로그인한 상태는 NAS에 자동 연결되지 않습니다. 비밀번호·쿠키를 채팅으로 보내지 마세요.

NAS 전용 브라우저에서 직접 로그인합니다. 화면·입력·세션은 이 Studio와 NAS 로그인 서비스 사이에서만 처리합니다. 저장된 세션은 접근 성공이나 다운로드 지원을 보장하지 않습니다.

PC에서 내보낸 로그인 세션 등록

사이트 전용 JSON 배열 또는 Netscape 내용을 아래에 붙여 넣으세요. 파일 선택도 가능합니다. 계정 로그인 쿠키만 NAS에 저장합니다. 사람 인증 쿠키는 가져오지 않으며 NAS에서 추가 인증이 필요할 수 있습니다. 파일을 채팅에 보내지 마세요.

E-Hentai·익헨 공용 계정 세션을 등록합니다. 원래 쿠키 도메인을 유지합니다.

현재 사이트:

아래 NAS 화면에서 입력란을 누르고 바로 타이핑하거나 붙여넣으세요. Enter·Tab·지우기·전체 선택을 사용할 수 있습니다. 사이트 제한·인증은 직접 완료해야 하며 자동 우회하지 않습니다. 한 번에 한 창을 열며, 30분 동안 조작하지 않으면 닫힙니다.

허용되지 않은 외부 요청이 차단됐습니다. 필요한 로그인 절차를 완료할 수 없다면 취소하세요.

화면을 클릭한 뒤 바로 입력하세요. 휠·세로 밀기로 스크롤합니다.

문자 입력 도구

비밀번호 입력 문자는 전송 직후 비웁니다. 세션은 NAS 전용 파일에 저장하며 메타데이터 내보내기에 포함하지 않습니다. 익헨 다운로드는 인증·동일 출처 검증 전까지 비활성 상태입니다. Hitomi는 이 화면에서 제공하는 로그인 기능이 없습니다.
