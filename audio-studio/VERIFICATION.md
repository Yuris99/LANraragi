# 로컬 검증 기록

2026-10-23 KST. 기반 커밋 `79f7dd70`, 브랜치 `feature/audio-studio`.

- 음성 서비스 테스트 20개 통과: 원작/네 판본 연결, 동일 제목 분리, 출처 namespace, 판본 간 출처 ID 충돌 거부, 원본 JSON 이력, 제작진/원본 필드 보존, DB 재개방, 타 DB·미지원 스키마 무변경 거부, 트랙 순서/중복/이어듣기, 유효성 검증, HTTP 흐름/내보내기, 실제 WAV 전체/byte-range/HEAD/416, 경로 이탈 차단, 인증·Host·CSRF, 정적 자산, 포트 중복 바인딩 거부.
- 기존 만화 Studio 테스트 18개 통과. 기존 소스는 변경하지 않았다.
- `node --check audio-studio/web/app.js` 통과.
- Windows 브라우저에서 임시 DB·60초 합성 무음 WAV로 확인: 네 판본 표시, 동일 제목 원작 추가 시 2개 유지, 선택한 원작에 별도 음성판 추가, 출처 등록·동일 출처의 원본 기록 2개 보존, 다른 판본에 같은 출처 연결 시 오류 표시, 출처 ID 검색, 트랙 등록·실제 디코딩/재생, 1.5배속, 일시정지 후 약 14초 이어듣기 기록 표시.
- 브라우저에서 발견한 Windows `.js` MIME 문제를 명시적인 `text/javascript` 응답으로 수정하고 회귀 검증에 포함했다.
- 브라우저 캡처는 커밋하지 않는 `test-results/browser-proof.png`에 저장했다. 캡처의 원작/출처 ID는 합성 테스트 데이터다.
- 테스트·브라우저 fixture는 전용 임시 DB를 사용하며 기본 `data/audio.sqlite3`를 만들거나 실제 미디어를 가져오지 않는다. 검증 후 임시 서버를 종료했다.

브라우저 검증은 좁은 화면의 데스크톱 내장 브라우저에서 수행했다. 실제 휴대폰·NAS·외부 사이트·실제 개인 라이브러리는 검증하지 않았다. 브라우저에서 이전/다음 자동 전환과 모든 등록 확장자의 코덱 재생까지 확인한 것은 아니다. 파일 형식별 호환성과 실제 운영 준비는 별도 검증이 필요하다.
